Ry/bohr² · basis-outer · Hermiticity 自检

转换逻辑（物理）

FC2（phonopy 文本格式）存的是超胞原子对之间的 3×3 力常数矩阵 Φαβ(I, J)，共 N×N 块，单位通常为 eV/Å²。IFC2（QE q2r / matdyn 的 .fc）存的是 原胞基元原子在格矢 R 上的力常数 Φαβ(κ, κ′; R)，单位为 Ry/bohr²。

转换的物理本质是晶体平移对称性约化：把超胞中每一对原子 分解为「基元指标 + 胞平移」，再按格矢归并。对基元原子 κ 固定在原点胞、 κ′ 位于胞 R 的情形，有

Φαβ(κ, κ′; R) = Φαβ( 超胞原子(0,κ), 超胞原子(R,κ′) ) × (eV/Å² → Ry/bohr²)

单位换算因子（CODATA）： (1/13.60569) / (1/0.529177)² ≈ 0.020582。 无需再乘质量——两种格式都是能量对位移的二阶导，质量在声子求解时才引入。

对称性约束用于校验与自动识别原子排序，而不是凭空生成数据： Hessian 对称性 Φαβ(κ,κ′;R) = Φβα(κ′,κ;−R)， 以及声学和规则 Σκ′,R Φ(κ,κ′;R) = 0。 工具会比较两种常见超胞原子排序（basis-outer / cell-outer），取 Hermiticity 误差更小者。
